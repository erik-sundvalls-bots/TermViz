A Snap2SNOMED map is a CSV or TSV with a header. The columns are source_code, source_display, target_code, target_display, and relationship_type. Several rows can share one source_code when there is more than one candidate. relationship_type is TARGET_EQUIVALENT, TARGET_BROADER, TARGET_NARROWER, or TARGET_INEXACT. The demo opens the extended map. The earlier candidate file is still on this site: extended map, first candidate map.
